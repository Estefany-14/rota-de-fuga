# Sistema de Rotas de Fuga - Colégio Otalípio Pereira de Andrade

## 📍 Localização
Bateias, Campo Largo - Paraná

## 🎯 Objetivo
Sistema interativo para identificar, documentar e mapear rotas de fuga e pontos de emergência em diferentes regiões de Bateias.

## 🚀 Como Usar

### Abrir o Sistema
1. Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Firefox, Edge)
2. O sistema carregará automaticamente

### Criar um Mapa de Rota de Fuga

1. **Selecione uma Região**
   - No painel esquerdo, clique em uma das regiões de Bateias:
     - Centro de Bateias
     - Bateias Industrial
     - Bateias Rural
     - Vila Nova
     - Jardim das Flores
     - Bairro São João

2. **Ative o Modo de Edição**
   - Clique no botão "✏️ Editar" no topo do painel do mapa
   - O botão mudará para "✏️ Editando" (vermelho)

3. **Adicione Elementos de Emergência**
   - Selecione um elemento no painel "Elementos de Emergência":
     - 🚪 Porta de Saída
     - 🪟 Janela
     - 🧯 Extintor
     - 💡 Luminária de Emergência
     - ⚠️ Ponto de Risco
     - 📍 Ponto de Encontro
   - Clique no mapa para posicionar o elemento selecionado
   - Repita para adicionar mais elementos

4. **Registre Riscos Identificados**
   - No painel "Riscos Identificados", clique em "➕ Adicionar Risco"
   - Descreva o risco encontrado (ex: "Corredor obstruído com cadeiras")
   - Os riscos aparecerão na lista

5. **Adicione Observações**
   - No campo "Observações", registre informações importantes sobre a rota
   - Exemplo: "A sinalização está visível, mas precisa de limpeza"

6. **Use o Checklist**
   - Marque os itens do checklist de verificação:
     - Rotas e saídas livres e desobstruídas
     - Sinalização visível e clara
     - Extintores acessíveis
     - Luminárias de emergência funcionando
     - Ponto de encontro identificado
     - Caminho até o ponto de encontro livre

7. **Salve o Mapa**
   - Clique no botão "💾 Salvar"
   - O mapa será salvo no navegador (localStorage)
   - Você pode fechar e reabrir o navegador, os dados serão mantidos

8. **Exporte o Relatório**
   - Clique no botão "📥 Exportar"
   - Um arquivo .txt será baixado com todas as informações
   - Use este relatório para comunicar à escola

### Remover Elementos
- No modo de edição, passe o mouse sobre um elemento no mapa
- Clique no botão ❌ que aparece para remover

## 📋 Checklist de Investigação em Campo

Durante o percurso da rota de fuga, observe:

### Rotas e Saídas
- ✓ Estão livres e desobstruídas?
- ✓ Em condições adequadas para passagem?

### Possíveis Riscos
- ✓ Há objetos, materiais ou lixo que dificultem a saída?
- ✓ Existem situações que ofereçam perigo?

### Sinalização
- ✓ É possível identificar o caminho até o Ponto de Encontro?
- ✓ Placas de emergência estão visíveis?

### Equipamentos
- ✓ Extintores estão acessíveis e na validade?
- ✓ Luminárias de emergência funcionando?

## ⚠️ Importante

Esta atividade é para **identificar e comunicar** possíveis riscos, e **NÃO** para:
- Fazer intervenções
- Movimentar equipamentos
- Tentar resolver problemas por conta própria

Comunique todos os riscos identificados à administração da escola!

## 💾 Dados Salvos

Todos os mapas são salvos automaticamente no navegador (localStorage). Para preservar os dados:
- Use o mesmo navegador sempre
- Não limpe o cache do navegador
- Exporte relatórios regularmente como backup

## 🏫 Sobre o Projeto

Este sistema foi desenvolvido para apoiar a atividade escolar de identificação de rotas de fuga, conforme as diretrizes de prevenção e segurança do Colégio Otalípio Pereira de Andrade.

**Lembre-se:** Em uma emergência, não é hora de descobrir o caminho. É hora de colocar em prática aquilo que já aprendemos e treinamos!
